# Essential project principles

## Scope and design

- Build the smallest complete solution to the current requirements. No speculative frameworks, placeholder extension types, or features added because “we may need them later.” Ask about material product/architecture choices before implementing them.
- Correctness first, then performance and maintainability. Prefer explicit typed models and boring, understandable code over needless abstraction.
- One Rust desktop executable: shared native market models, an in-process exchange-data library, iced desktop, and an iced-independent indicator library. No localhost REST/WebSocket server, serialized inter-process feed, or companion process. External exchange protocols remain native.
- Support native Linux, Windows and macOS builds; Omarchy is an optional Linux integration, not a runtime dependency. Keep platform filesystem/windowing details at their boundaries and verify default-feature native builds in CI; cross-checks never substitute for native graphical runtime evidence.
- Custom chart geometry on iced Canvas—not a charting library or custom GPU engine. One current chart: Binance, OKX, Coinbase, or MEXC; native spot or true perpetuals; native USD/USDT/USDC quote where listed. A fresh workspace starts MEXC perpetual BTC_USDC/5m; normal launches restore the saved exact market after catalog validation. Never silently substitute a venue, product, currency, dated future, unavailable symbol, or resampled bars. Quote and settlement differ for inverse perpetuals.
- No trading, accounts, standalone notes, alerts, scripting, or database. Workspace persistence is on by default: restore committed indicators, profile configurations, price-chart drawing books, quick markets and chart presentation. Fresh workspaces have no indicators/profiles/drawings. Text annotations are drawings, not a separate notes system. Extend structured state, not speculative plugin or named-workspace systems.

## State is the source of truth

- Selected exchange/product/symbol/interval, candles, viewport, inspection, indicator/profile configurations and calculated outputs, and drawing books/history are structured data independent of rendering. The GUI is only a representation and input adapter.
- Candles are chronological and unique by opening timestamp, using UTC Unix seconds; prices use the native quote currency. Drawing anchors and native OI observations retain UTC milliseconds. Preserve and label native base-asset or contract volume, including fractional quantities; never guess inverse/base-volume conversions.
- Indicator instances have stable IDs, typed parameters, and independent visibility. Calculated outputs align with candles; native-backed OI retains independent observation timestamps. Multiple instances remain independently configurable, hideable, and removable.
- Profiles have stable IDs and independent visibility. Session/visible profiles follow the active native instrument; fixed profiles retain exact native exchange/product/symbol bindings across interval changes and become dormant elsewhere. Do not use another instrument's price/tick reference to rebin or place a bound profile.
- TPO explicitly uses independent native 1-minute bar ranges, not tick-by-tick reconstruction. Volume Profiles prefer actual priced native executions/aggregates and default to explicitly labeled candle fallback for unproved native minutes. Replace a partial minute's executions with its native candle estimate, never double count; certified execution recovery replaces estimates. Native quantities remain Decimal with bounded allocation precision/conserved remainder. Estimated/Mixed never certifies exact coverage or reference origins. Provide a persistent exact-only option. Never guess price ticks, substitute venues, or silently convert contract/notional units; estimation does not alter CVD/OI.
- Profile POC/value-area/grid conventions are explicit and deterministic. Native Initial Balance extremes are not rounded bin edges; interior Single Prints, tails and poor extreme rows remain distinct. Only certified closed origins mint previous/naked references; positive touches survive gaps, while missing lifecycle evidence stays unproved. Custom IANA sessions retain actual UTC windows and documented DST/gap/overlap behavior.
- CVD/OI source selection is per instance: Chart, one exact native market, selected aggregate, or All eligible exchanges with explicit native choices. Same catalog underlying/product only; CVD requires the exact native interval, while OI keeps independent native times. Failed discovery cannot silently remove a required venue.
- All uses the same native eligibility rule in composition and calculation. Revalidate after native context, source/spec or discovery changes even with settings closed; pending/failed/malformed discovery or missing eligible venues invalidate current and historical totals for an uncertified universe. Never silently choose/remove native membership to regain a subset. Preserve compatible raw inputs for repair, and keep unchanged ticks cached.
- Invalid configuration must leave the existing instance unchanged. Insufficient history is represented by missing values, never fabricated zeroes. Document numerical seeds and flat-market conventions; do not claim vendor-exact parity.
- CVD consumes native aggressor-volume quantities only. Confirmed native flow, MEXC reported/unconfirmed direction, and missing coverage are distinct. Never estimate historical execution flow from price/OHLC, count ratios, or shallow recent-trade samples. Preserve native units and exact decimal arithmetic before the final floating conversion.
- CVD origin/reset/coverage are explicit structured state. Continuous sums never silently restart across a missing middle interval; UTC-day sums require proven midnight coverage. Absolute flow snapshots have independent volume/as-of bounds. Missing history cannot revoke newer measured live coverage, but disconnects revoke unfinished capture.
- OI consumes actual native outstanding quantities, never a volume/CVD/notional proxy. Preserve native contracts/base units, millisecond source observations, cadence gaps, exclusive history cursors, and source retention. Untimestamped native snapshots use explicitly observed receipt time, never another field's quote/trade timestamp. Unsupported/history-unavailable is not zero; finer candle intervals never fabricate finer OI samples.
- VWAP is native-candle HLC3 weighted by native candle volume, explicitly a candle approximation rather than tick/execution VWAP. Share one incremental engine for typed UTC/calendar/IANA daily resets and anchored starts; preserve native volume units. Track true origin and contiguous native coverage; missing history/boundary alignment remains partial, zero volume has no fabricated price, and lines never bridge resets/native gaps. Exclude session-straddling candles instead of inventing prorated weights.
- External sources aggregate authoritative base-asset quantities, never incompatible raw contracts. Scale linear contracts using native metadata; inverse flow uses actual native base fields or per-execution prices, never candle-close/average-price conversion. Unsupported units are explicit. Sum proven raw CVD deltas before one common-origin/reset accumulation with weakest quality; every selected source is required. OI requires all contributors fresh within declared cadence tolerance and exposes asynchronous min/max as-of plus timestamp provenance. Hide incomplete current totals while retaining proven history.
- Switching exchange/product/symbol/interval preserves indicator IDs, parameters, and visibility while clearing candles and calculated outputs; recalculate on the new bars. Native OI survives interval-only changes of the same instrument, but never another instrument. Reset the latest viewport with live following and auto-fit. Use instrument precision and tick-sized bounds, not a fixed two-decimal/cent scale.
- Recent/favorite markets persist exact exchange/product/native-symbol/interval identity and MRU ordering. Revalidate native catalog choices before every quick switch or restoration; an unavailable saved interval or symbol is an explicit repair case, never a substitute.
- Drawing books use exact exchange/product/native-symbol identity, excluding interval. Preserve committed objects, stable IDs, UTC-millisecond/native-price anchors, semantic appearance, visibility and locking across instrument return, timeframe changes and relaunch. Undo/redo, selection and uncommitted gestures are not durable. Invalid/no-op edits leave committed state/history intact; locks prevent geometry/content/appearance changes without blocking explicit visibility, unlock or deletion.
- Anchored VWAP is an ordinary native drawing-book object with a UTC-millisecond start only; derive prices from native candles, never save/free-drag a fake price anchor. The curve selects, its start handle moves, and keyboard placement/nudging uses real native candles. Share cached derived geometry between drawing, picking and cursor feedback; keep full source/partial disclosure in properties and compact labels on the plot. Persist configuration, not values or coverage.
- Measurement counts actual inclusive loaded native bars, not elapsed-time/interval estimates. Keep signed price/percentage/time, undefined percentage at zero origin, and partial-history coverage explicit. Repeat is opt-in, remains armed only after a successful commit, and Escape disarms it.

## Every action supports keyboard and mouse

- Keyboard, mouse, and buttons dispatch the same typed commands. Future input adapters must use that path rather than duplicate behavior.
- Entire workflows must be keyboard-accessible: exchange/product/quote selection, native instrument search, timeframe selection, navigation, both-axis zoom/pan, inspection, history loading, indicator/profile add/edit/show-hide/remove, profile options/session/range placement, drawing creation/selection/editing/style/visibility/locking/deletion/undo-redo, and scrolling panes/legends/object lists. No mouse-only controls.
- Respect focus: symbol search and parameter editing must not trigger chart shortcuts. Opening an indicator editor or changing its type/instance must focus/select the first numeric parameter field where present; CVD uses a typed reset selector, not a free-text token. Stable field IDs preserve Tab traversal. Provide visible, readable shortcuts and explicit validation feedback.
- Profile and indicator parameter selection, type/mode changes, and Tab traversal reveal the focused field using actual native widget/scroll geometry, including narrow stacked editors. Do not guess scroll offsets from row heights or silently alter fixed millisecond bounds when unrelated display settings are applied.
- Profile inspection is a stable single-line layout slot: hovering must not insert/remove/wrap header rows and move the price plot under the cursor. Expose TPO/visible VP in the ordinary indicator type chooser and selected-range VP in Draw. Fixed-profile selection/body/endpoint edits use explicit rails, preserve native binding and view, respect drawing/gesture priority and Space-pan, and persist as profile configuration rather than drawing-book history.
- Keep the chart header compact instead of permanent action-button bars and footer shortcut descriptions. Expose symbol, native interval, Indicators, Draw, and contextual exact-instance controls. Direct interval selection must validate against the active native catalog independently of cancelled editor drafts. A discoverable F1 / ? popup must show keyboard/mouse bindings, preserve editor drafts/focus and all scroll positions, and block background input/overlays while live data continues. Keep background widget trees mounted; disable chart actions in editor-context help.
- Ctrl+K searches the same typed actions as keyboard/mouse controls and reuses the help navigation registry. Editor contexts exclude chart/drawing mutations; cancellation preserves the exact previously focused field and drafts. Search intent such as an existing indicator's settings must not silently add another instance.
- Market/settings/details dialogs must adapt to the available window without squeezing or unmounting the chart. Keep actions and validation in fixed footers; scroll only content. Block queued chart navigation as well as background pointer/keyboard/dropdown input while native data continues.
- Dialog panels own presses on blank space, padding, labels, and already-selected controls. Only an actual outside press may dismiss through the backdrop; dropdown selection and an inside press released outside must not cancel a draft.
- Use one theme-derived visual system for quiet navigation, primary commits, destructive actions, selected rows, fields, surfaces, and keycaps. Keep a single outer dialog shell, proportional simple-dialog heights, grouped native numeric readouts and property sections, fixed action/validation footers, and scrollbar insets. Responsive layout must not clip focused fields or hide keyboard access to parameters/source choices; PageUp/PageDown scroll those editors.
- Reduce repeated instructions before adding visual emphasis. Use compact theme-derived identity/selection, eligibility, and coverage badges with explicit labels, not color-only states. Eligibility is not live coverage; historical context is not current-source completeness. Keep native units and blockers visible, disclose verbose provenance in keyboard-accessible Details, and preserve monochrome theme intent.
- Source composition uses visible mode radios, Single exact-market radios and Selected/All checkboxes. The exchange checklist separates browsing/cursor from actual inclusion, shows eligibility/discovery/required-missing state, and retains unavailable choices for explicit removal. Apply stays transactional; Single replacement and venue removal require explicit user actions.
- Keep legends compact, but never hide truth-critical units, historical/current context, CVD quality/origin, or OI as-of/provenance. Use readable disclosure text and Details for verbose contributors/cadence/status. Group operational summaries separately from raw status/error detail. Source incompatibility must name the context and offer exact-instance repair or an explicit Chart-source cutover; never silently substitute membership.
- Contributor health/remedies are typed current state: name exact blocked scopes and distinguish waiting, discovery retry, producer retry, and configuration repair. Revoke only retry-affected shared generations, retain unrelated healthy producers, and explicitly retry failed catalog results without breaking successful/in-flight sharing.
- Panning/zooming time away from live preserves the user's viewport while data continues updating. Prepending history must not shift it. Expose Return to realtime only when following is stopped; it preserves manual value scales, while reset restores time and every scale without resetting CVD counters/origins.
- UTC jumps navigate time only and page ordinary native history in chronological order. Stop on exhaustion or nonprogress, preserve gaps and numerical scales, reject invalid input without draft loss, and cancel pending intent on manual time navigation/live/reset/native market changes. Never fabricate historical or future bars.
- Indicator panes share time navigation and inspection, with independent automatic/manual value scales and keyboard-accessible target selection. Axis gestures are pointer-anchored; manual bounds survive ticks, older history, configuration, and hide/show. Keep panes/readouts usable in narrow windows and with many instances. Show inspected UTC time on each bottom axis; cursor movement must not invalidate base geometry.
- Pane heights/collapse/order and manual bounds are stable-ID durable presentation—not visibility or data configuration. Resizing must leave time, numeric bounds, inspection and CVD origins untouched. Collapse keeps summaries and feeds alive; retain layout through edits, hide/show, native context changes and relaunch, discard it on removal/overlay conversion, and cancel held resize input on modal entry.
- Resize capture is anchored to the press and surviving pane geometry, not immediate acknowledgement of the last requested height. Continue through burst/partial view updates; independent keyboard/layout changes explicitly revoke the older gesture.
- Reordering swaps adjacent visible lower panes without cloning/calculating histories. Temporary maximization preserves saved layouts/scales/source context, keeps keyboard input on the shown target, and restores normal presentation when the target is hidden, removed, or converted to an overlay.
- Price/lower plots use one wheel/pixel policy: shared time navigation, explicit Shift value zoom, Alt plot-stack scroll, and axis ownership taking precedence. Generate bounded nice value/UTC calendar ticks with width/height-aware labels; never present reset epoch/0–1 bounds as initialized data. Abbreviate quantities, not units; expose unabridged values and preserve native price precision.
- Drawing input belongs only to the price plot; axes/grips take precedence and Space-drag temporarily restores ordinary navigation. Use actual visible candle OHLC for optional magnet placement, not invented ticks. Separate transient previews from committed books, produce one undo step per completed gesture, cancel held edits on modal/context/window exit, and reject stale gesture messages.
- A press owns its target and coordinate frame until release/cancellation. Context chrome must not resize/remount the plot and must yield to held input. Capture is authoritative for routing, hover, cursor, and preview; redraw/live transforms are not new edit events. Space chooses navigation before a press, never steals an ongoing drawing edit. Cancel each plot/grip's held input explicitly on focus loss, resize and native context changes while preserving unrelated scroll state; iced 0.13 list keys alone are not a cancellation barrier.
- Normalize batched mouse positions at the window root before scrolling transforms. Plot/grip consumers use the routed content-space cursor, never raw window coordinates; unavailable/clipped cursors must stay unavailable.

## Performance and live-data correctness

- Draw only the visible range; cache candle/axis/indicator geometry separately from inspection and price overlays. Clip offscreen series/histograms before dashed expansion/tessellation. Never calculate indicators during rendering or crosshair movement; value-only interactions invalidate only the affected pane.
- Cache committed drawings independently from candles/indicators and keep selection/hover/gesture overlays uncached. Clip before dash expansion, measure/render native text consistently, borrow drawing payloads during previews, and use delta history rather than whole-book copies. Drawing edits must not clear data geometry, refit numeric scales, recalculate indicators, restart producers, or alter CVD origins.
- Budget cached annotation layouts by shaped glyph payload rather than a tiny label count, so dense short-price labels reuse native shaping. Keep oversized layouts uncached and the active dragged annotation separately pinned. Renderer benchmarks must label synthetic fixtures, separate event-loop notification from GPU presentation, and disclose mixed cache-hit/rebuild percentiles and cold-start maxima.
- Borrow contiguous candle storage. No full-history cloning/recalculation or avoidable allocation on ordinary live-tail updates; reuse output storage.
- Replacing the forming candle must recompute from the preceding finalized state—not advance EMA/Wilder accumulators repeatedly. Corrections recalculate the affected suffix; historical prepends reseed. More loaded history can legitimately change recursive values.
- Anchored VWAP updates only after native time/OHLC/volume changes, relevant configuration changes or anchor previews; flow-only enrichment, hover and navigation never recompute it. Automatic origin loading reuses the native history pager without moving the viewport; exhausted/nonadvancing cursors and unavailable interior history never become fabricated complete coverage.
- Ordered native flow batches walk candles once, recalculate one affected CVD suffix, and invalidate CVD geometry rather than price/other indicators. Preserve status/revocation boundaries; do not coalesce away coverage transitions. Share catalogs/history pages and subscription scope instead of copying/serializing them. Keep live ID caches bounded. Additional tape/replay work runs only for actual CVD/profile consumers, including hidden instances; Binance CVD retains its cheaper native kline path. Stream prices before cancellable replay; pace shared native request budgets without holding locks across waits.
- Share required external sources per native market and data kind, including hidden instances; keep CVD and OI lifetimes independent. Chart-native OI shares a separately scoped producer. Native live append reuses chronological storage; page merges avoid repeated insertion/full-history copies, and source-only updates invalidate only affected panes. Cancel on last-reference removal; reject stale callbacks across removal/re-addition and scope changes. Keep history errors visible without blocking live observations.
- Profile aggregation runs off the GUI thread with separate source-kind history windows, native identities, canonical proof/revocation, and generation/request fences. Share priced live producers with compatible CVD consumers, but never suppress replay rows needed by a lagged subscriber. Retain inflight bulk history, repair only the newer tail, and stop unneeded live producers for closed static ranges. Cache source contributions/mitigation rather than replaying the full tape on ordinary updates.
- REST snapshots must not overwrite newer streaming observations. Preserve chronological deduplication and exclusive history cursors across differing native page limits. Every asynchronous chart callback is scoped by full market identity and selection generation; external feeds have native-market/data-kind ownership generations, and catalog callbacks have independent scope/generation. Discard stale responses before pipeline changes, even after A→B→A.
- Own native producers and their children for the selected chart, with pooled HTTP connections, bounded channels/batches, and visible disconnected states. Prefer native candle WebSockets; label native REST polling. Dropping/cancelling a subscription stops upstream I/O; reconnect repairs missed history and multi-page gaps. Catalog discovery is independently single-flight/cached per exchange/product, with no lock held across network awaits or substituted data after failure.
- Native market data is memory-only. Ordinary loaded candle history has no session-memory cap; profile source/contribution/row/archive budgets are explicit and fail visibly without silent rebinning, false completeness, or fabricated values. Durable JSON contains configuration only, never candles, priced executions, numerical outputs, raw contributor observations, connection state or proven coverage. Restored CVD/OI/profiles must reestablish native coverage. Do not claim a total session-memory bound or benchmarked performance without evidence.
- Save committed configuration by default under the native per-user application-state directory (Linux XDG, macOS Application Support, Windows Local AppData), with an absolute XDG override for isolated/custom storage. Use desktop-only versioned DTOs, native process locks, debounced revision-ordered synchronized atomic checkpoints and last-good recovery. Unix permissions and Windows inherited ACLs are distinct; never pretend chmod/directory fsync applies on Windows. Windows uses write-through replacement and durable reset-marker retirement, never delete-before-rename. Never capture histories or save on native ticks/unapplied drafts. Flush the latest revision before normal close; failures require explicit retry or exit without saving. Unsupported newer schemas remain byte-preserved until explicit full reset; tests/stress never touch user state.
- Confirmed Clear current chart preserves exact market/interval, other instruments' fixed profiles/drawing books and quick lists while clearing all indicators, chart-following/current-native profiles, and current-book objects including hidden/locked, layouts, drafts and interactions. Reset everything restores defaults and removes all profiles/books/quick lists/preferences/recovery data, never desktop/theme configuration. Confirmation discloses profile removal and defaults to Cancel. A durable reset intent and generation/revision fences prevent interrupted recovery or older callbacks/writes from resurrecting deleted state.

## Theme and verification

- Provide colorful, legible standalone defaults on every platform. On Linux, optionally discover/reload the Omarchy palette at `~/.local/state/omarchy/current/theme/colors.toml`, respecting absolute XDG paths; missing optional files are normal, not errors. An explicit `MEXC_CHART_THEME` file works on every OS. Never modify desktop configuration.
- Retain the last valid palette during unreadable/malformed/missing selected replacements and show the error; an explicitly configured missing file also remains an error. Never silence real theme failures or fall back to a different selected file. Distinguish indicators with IDs, labels, and line patterns—not color alone, especially in monochrome themes.
- Resolve plot contrast from semantic palette colors at load/reload, not per tick. Keep grids subordinate, cursor/readout contrast explicit, and candle direction distinguishable through hollow rising versus filled falling bodies when colors coincide.
- Numerical tests must cover actual values, warmup boundaries, repeated live replacement, corrections/prepends, and instance independence. Build/tests alone do not prove rendering or interaction: exercise a real native desktop window and native exchange data, naming the tested OS/backend. Linux-only memory diagnostics stay explicitly unavailable elsewhere. Explicitly report unavailable listings instead of fabricating coverage.
- Preserve the iced 0.13 layering fix: draw backgrounds in a separate clipped layer before clipped candles/series; pending parent-frame meshes can otherwise cover them.
- Update the README when behavior/contracts change, remove temporary smoke scaffolding, and stop verification processes afterward. Report only observed verification; no unsupported parity or performance claims.
