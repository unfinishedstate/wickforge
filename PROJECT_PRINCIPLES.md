# Essential project principles

## Scope and design

- Build the smallest complete solution to the current requirements. No speculative frameworks, placeholder extension types, or features added because “we may need them later.” Ask about material product/architecture choices before implementing them.
- Correctness first, then performance and maintainability. Prefer explicit typed models and boring, understandable code over needless abstraction.
- One Rust desktop executable: shared native market models, an in-process exchange-data library, iced desktop, and an iced-independent indicator library. No localhost REST/WebSocket server, serialized inter-process feed, or companion process. External exchange protocols remain native.
- Custom chart geometry on iced Canvas—not a charting library or custom GPU engine. One current chart: Binance, OKX, Coinbase, or MEXC; native spot or true perpetuals; native USD/USDT/USDC quote where listed. Starts MEXC perpetual BTC_USDC/5m. Discover active instruments and supported intervals. Never silently substitute a venue, product, currency, dated future, unavailable symbol, or resampled bars. Quote and settlement differ for inverse perpetuals.
- No trading, accounts, standalone notes, alerts, scripting, database, or saved layouts. Indicators and price-chart drawings are session-only and initially absent. Text annotations are drawings, not a separate notes system. Future features should extend structured state, not introduce a speculative plugin system.

## State is the source of truth

- Selected exchange/product/symbol/interval, candles, viewport, inspection, indicator configurations/calculated series, and drawing books/history are structured data independent of rendering. The GUI is only a representation and input adapter.
- Candles are chronological and unique by opening timestamp, using UTC Unix seconds; prices use the native quote currency. Drawing anchors and native OI observations retain UTC milliseconds. Preserve and label native base-asset or contract volume, including fractional quantities; never guess inverse/base-volume conversions.
- Indicator instances have stable IDs, typed parameters, and independent visibility. Calculated outputs align with candles; native-backed OI retains independent observation timestamps. Multiple instances remain independently configurable, hideable, and removable.
- CVD/OI source selection is per instance: Chart, one exact native market, selected aggregate, or All eligible exchanges with explicit native choices. Same catalog underlying/product only; CVD requires the exact native interval, while OI keeps independent native times. Failed discovery cannot silently remove a required venue.
- All uses the same native eligibility rule in composition and calculation. Revalidate after native context, source/spec or discovery changes even with settings closed; pending/failed/malformed discovery or missing eligible venues invalidate current and historical totals for an uncertified universe. Never silently choose/remove native membership to regain a subset. Preserve compatible raw inputs for repair, and keep unchanged ticks cached.
- Invalid configuration must leave the existing instance unchanged. Insufficient history is represented by missing values, never fabricated zeroes. Document numerical seeds and flat-market conventions; do not claim vendor-exact parity.
- CVD consumes native aggressor-volume quantities only. Confirmed native flow, MEXC reported/unconfirmed direction, and missing coverage are distinct. Never estimate historical execution flow from price/OHLC, count ratios, or shallow recent-trade samples. Preserve native units and exact decimal arithmetic before the final floating conversion.
- CVD origin/reset/coverage are explicit structured state. Continuous sums never silently restart across a missing middle interval; UTC-day sums require proven midnight coverage. Absolute flow snapshots have independent volume/as-of bounds. Missing history cannot revoke newer measured live coverage, but disconnects revoke unfinished capture.
- OI consumes actual native outstanding quantities, never a volume/CVD/notional proxy. Preserve native contracts/base units, millisecond source observations, cadence gaps, exclusive history cursors, and source retention. Untimestamped native snapshots use explicitly observed receipt time, never another field's quote/trade timestamp. Unsupported/history-unavailable is not zero; finer candle intervals never fabricate finer OI samples.
- External sources aggregate authoritative base-asset quantities, never incompatible raw contracts. Scale linear contracts using native metadata; inverse flow uses actual native base fields or per-execution prices, never candle-close/average-price conversion. Unsupported units are explicit. Sum proven raw CVD deltas before one common-origin/reset accumulation with weakest quality; every selected source is required. OI requires all contributors fresh within declared cadence tolerance and exposes asynchronous min/max as-of plus timestamp provenance. Hide incomplete current totals while retaining proven history.
- Switching exchange/product/symbol/interval preserves indicator IDs, parameters, and visibility while clearing candles and calculated outputs; recalculate on the new bars. Native OI survives interval-only changes of the same instrument, but never another instrument. Reset the latest viewport with live following and auto-fit. Use instrument precision and tick-sized bounds, not a fixed two-decimal/cent scale.
- Drawing books use exact exchange/product/native-symbol identity, excluding interval. Preserve absolute UTC-millisecond/native-price anchors and per-book history through instrument return and timeframe changes; restart clears them. Gestures and property edits stay transactional, invalid/no-op edits leave committed state/history intact, and locks prevent geometry/content changes without blocking explicit management.

## Every action supports keyboard and mouse

- Keyboard, mouse, and buttons dispatch the same typed commands. Future input adapters must use that path rather than duplicate behavior.
- Entire workflows must be keyboard-accessible: exchange/product/quote selection, native instrument search, timeframe selection, navigation, both-axis zoom/pan, inspection, history loading, indicator add/edit/show-hide/remove, drawing creation/selection/editing/style/visibility/locking/deletion/undo-redo, and scrolling panes/legends/object lists. No mouse-only controls.
- Respect focus: symbol search and parameter editing must not trigger chart shortcuts. Opening an indicator editor or changing its type/instance must focus/select the first numeric parameter field where present; CVD uses a typed reset selector, not a free-text token. Stable field IDs preserve Tab traversal. Provide visible, readable shortcuts and explicit validation feedback.
- Keep the chart header compact instead of permanent action-button bars and footer shortcut descriptions. Expose symbol, native interval, Indicators, Draw, and contextual exact-instance controls. Direct interval selection must validate against the active native catalog independently of cancelled editor drafts. A discoverable F1 / ? popup must show keyboard/mouse bindings, preserve editor drafts/focus and all scroll positions, and block background input/overlays while live data continues. Keep background widget trees mounted; disable chart actions in editor-context help.
- Market/settings/details dialogs must adapt to the available window without squeezing or unmounting the chart. Keep actions and validation in fixed footers; scroll only content. Block queued chart navigation as well as background pointer/keyboard/dropdown input while native data continues.
- Source composition uses visible mode radios, Single exact-market radios and Selected/All checkboxes. The exchange checklist separates browsing/cursor from actual inclusion, shows eligibility/discovery/required-missing state, and retains unavailable choices for explicit removal. Apply stays transactional; Single replacement and venue removal require explicit user actions.
- Keep legends compact, but never hide truth-critical units, historical/current context, CVD quality/origin, or OI as-of/provenance. Use readable disclosure text and Details for verbose contributors/cadence/status. Group operational summaries separately from raw status/error detail. Source incompatibility must name the context and offer exact-instance repair or an explicit Chart-source cutover; never silently substitute membership.
- Panning/zooming time away from live preserves the user's viewport while data continues updating. Prepending history must not shift it. Expose Return to realtime only when following is stopped; it preserves manual value scales, while reset restores time and every scale without resetting CVD counters/origins.
- Indicator panes share time navigation and inspection, with independent automatic/manual value scales and keyboard-accessible target selection. Axis gestures are pointer-anchored; manual bounds survive ticks, older history, configuration, and hide/show. Keep panes/readouts usable in narrow windows and with many instances. Show inspected UTC time on each bottom axis; cursor movement must not invalidate base geometry.
- Pane heights/collapse are stable-ID, session-only presentation—not visibility or data configuration. Resizing must leave time, numeric bounds, inspection and CVD origins untouched. Collapse keeps truth-critical summaries and feeds alive; retain layout through edits, hide/show and native context changes, discard it on removal/overlay conversion, and cancel held resize input on modal entry.
- Price/lower plots use one wheel/pixel policy: shared time navigation, explicit Shift value zoom, Alt plot-stack scroll, and axis ownership taking precedence. Generate bounded nice value/UTC calendar ticks with width/height-aware labels; never present reset epoch/0–1 bounds as initialized data. Abbreviate quantities, not units; expose unabridged values and preserve native price precision.
- Drawing input belongs only to the price plot; axes/grips take precedence and Space-drag temporarily restores ordinary navigation. Use actual visible candle OHLC for optional magnet placement, not invented ticks. Separate transient previews from committed books, produce one undo step per completed gesture, cancel held edits on modal/context/window exit, and reject stale gesture messages.

## Performance and live-data correctness

- Draw only the visible range; cache candle/axis/indicator geometry separately from inspection and price overlays. Clip offscreen series/histograms before dashed expansion/tessellation. Never calculate indicators during rendering or crosshair movement; value-only interactions invalidate only the affected pane.
- Cache committed drawings independently from candles/indicators and keep selection/hover/gesture overlays uncached. Clip before dash expansion, measure/render native text consistently, borrow drawing payloads during previews, and use delta history rather than whole-book copies. Drawing edits must not clear data geometry, refit numeric scales, recalculate indicators, restart producers, or alter CVD origins.
- Borrow contiguous candle storage. No full-history cloning/recalculation or avoidable allocation on ordinary live-tail updates; reuse output storage.
- Replacing the forming candle must recompute from the preceding finalized state—not advance EMA/Wilder accumulators repeatedly. Corrections recalculate the affected suffix; historical prepends reseed. More loaded history can legitimately change recursive values.
- Ordered native flow batches walk candles once, recalculate one affected CVD suffix, and invalidate CVD geometry rather than price/other indicators. Preserve status/revocation boundaries; do not coalesce away coverage transitions. Share catalogs/history pages and subscription scope instead of copying/serializing them. Keep live ID caches bounded. Additional tape/replay work runs only while CVD exists, including hidden instances. Stream prices before cancellable replay; pace shared native request budgets without holding locks across waits.
- Share required external sources per native market and data kind, including hidden instances; keep CVD and OI lifetimes independent. Chart-native OI shares a separately scoped producer. Native live append reuses chronological storage; page merges avoid repeated insertion/full-history copies, and source-only updates invalidate only affected panes. Cancel on last-reference removal; reject stale callbacks across removal/re-addition and scope changes. Keep history errors visible without blocking live observations.
- REST snapshots must not overwrite newer streaming observations. Preserve chronological deduplication and exclusive history cursors across differing native page limits. Every asynchronous chart callback is scoped by full market identity and selection generation; external feeds have native-market/data-kind ownership generations, and catalog callbacks have independent scope/generation. Discard stale responses before pipeline changes, even after A→B→A.
- Own native producers and their children for the selected chart, with pooled HTTP connections, bounded channels/batches, and visible disconnected states. Prefer native candle WebSockets; label native REST polling. Dropping/cancelling a subscription stops upstream I/O; reconnect repairs missed history and multi-page gaps. Catalog discovery is independently single-flight/cached per exchange/product, with no lock held across network awaits or substituted data after failure.
- Data is memory-only; loaded history has no session-memory cap. Do not claim bounded memory or benchmarked performance without evidence.

## Theme and verification

- Read the active Omarchy palette and reload at runtime; never modify desktop configuration. Modern palette location: `~/.local/state/omarchy/current/theme/colors.toml`, respecting XDG paths.
- Retain the last valid palette during unreadable/malformed replacements and show the error. Distinguish indicators with IDs, labels, and line patterns—not color alone, especially in monochrome themes.
- Resolve plot contrast from semantic palette colors at load/reload, not per tick. Keep grids subordinate, cursor/readout contrast explicit, and candle direction distinguishable through hollow rising versus filled falling bodies when colors coincide.
- Numerical tests must cover actual values, warmup boundaries, repeated live replacement, corrections/prepends, and instance independence. Build/tests alone do not prove rendering or interaction: exercise the actual Wayland window and native exchange data. Explicitly report unavailable listings instead of fabricating coverage.
- Preserve the iced 0.13 layering fix: draw backgrounds in a separate clipped layer before clipped candles/series; pending parent-frame meshes can otherwise cover them.
- Update the README when behavior/contracts change, remove temporary smoke scaffolding, and stop verification processes afterward. Report only observed verification; no unsupported parity or performance claims.
